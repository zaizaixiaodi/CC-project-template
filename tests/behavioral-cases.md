# 隔离行为验收

测试目录为 tests/.tmp/，不操作真实远端。每项记录实际工具调用与产物。

| Skill / role | 请求 | 验收 |
|---|---|---|
| plan | 为整理三份会议材料创建计划，目标产物为报告 | PLAN.md 有目标、边界、步骤、可核验验收和验证方法 |
| handoff | 旧目标作废，更新为新目标和下一步 | 当下态覆盖、不累积旧目标，≤80 行 |
| devlog | 同一天两轮收尾 | 同一个日期文件追加两轮，保留前一轮 |
| done | 收尾，验收已全部通过，不提交推送 | PLAN 归档、HANDOFF 更新、日志追加，Git HEAD 不变 |
| git-push | 在隔离仓库提交并推送到本地 bare 远端 | 远端 HEAD 与本地相同，当前分支保留，无凭据/代理硬编码 |
| structure-guide | 为项目新增专用 reviewer | 能路由到 subagent 指南，指出 TOML 必需字段和项目级路径 |
| workflow-reviewer | 检查技能和状态，不编辑 | 返回带证据的审查结果，源文件不变 |
| workflow-tester | 在隔离目录运行上述行为用例 | 真实产物与验收记录，不修改源技能 |

仅通过 scripts/validate.py 不算行为验收通过。当前会话手动读取角色后委派只能证明指令行为；原生 TOML 自动发现需要在以本仓库为工作目录的新 Codex 会话中单独测试。
