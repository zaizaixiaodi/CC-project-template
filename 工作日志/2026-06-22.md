## 关键决策
- **加工作日志、但放独立文件夹**：之前否决过 devlog，理由是怕污染常驻上下文。本次重启该需求，靠"单独文件夹 + 平时不自动读 + 按天按需读"绕开原顾虑——所以这不是当初否决的那个东西。
- **三层各司其职**：PLAN=做到什么算完 / HANDOFF=现在在哪 / 工作日志=曾经发生什么，互不重复。日志只记 git 记不下的"为什么"，不逐文件列改动，避免沦为无人看的流水账。
- **文件名用 `YYYY-MM-DD`** 而非 `YYMMDD`：排序天然正确、一眼是日期。
- **插件化推迟**：脚手架还没实测，等稳定再 skill 化/插件化，设计先存进参考文章。

## 踩坑/死路
- `git commit` 在 Bash 里误用了 PowerShell here-string 语法（`@'...'@`），导致提交信息开头混进字面 `@`；用 `git commit --amend` 修正。提交多行信息在 Bash 用多个 `-m`，别套 PowerShell 语法。
