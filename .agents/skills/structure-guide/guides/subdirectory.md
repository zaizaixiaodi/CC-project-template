# 模块指令

当某目录有专属命令、边界或约定时，在该目录创建 `AGENTS.md`，只写与根指令不同的内容。目录数量不是必须拆分的依据。

Codex 启动时沿项目根到当前工作目录构建指令链，更具体的指令后加载。每个目录优先选择 `AGENTS.override.md`，否则选择 `AGENTS.md`；不要假定兄弟目录指令都已自动加载。

```markdown
# 模块名称

## 范围
本目录负责的业务与边界。

## 专属约定
- 本模块不同于根项目的规则。

## 验证
- 本模块实际可执行的检查命令。
```

在根指令添加导航指针。验证时从模块目录启动一个新会话，检查加载来源和采用的命令。跨模块工作先读取涉及模块的指令，避免遗漏。

来源：[官方加载与覆盖规则](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。
