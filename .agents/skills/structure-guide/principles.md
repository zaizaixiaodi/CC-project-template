# 通用原则

| 内容 | 存放位置 |
|---|---|
| 全项目约定、命令与文档指针 | 根 `AGENTS.md` |
| 模块约定 | 模块内 `AGENTS.md` |
| 可复用工作流 | `.agents/skills/<name>/SKILL.md` |
| 独立角色 | `.codex/agents/<name>.toml` |
| 运行配置 | `.codex/config.toml` |
| 团队背景知识 | `docs/` 等项目文档 |

默认修改项目文件，沿用现有结构，避免重复。个人全局配置只在用户要求时修改；模板不写入用户凭证、固定模型或机器绝对路径。

指令说明事实与约定，skill 描述流程，subagent 定义职责。权限由运行环境执行，不能靠提示词代替。不要假定个人自动记忆会随仓库共享。

本模板建议根指令和 skill 入口不超过 200 行，模块指令保持简短；这是维护目标，不是 Codex 官方加载上限。细节用可解析的相对链接引用。

使用当前 Codex 文档验证版本相关字段。不要直接保留旧工具的专属 frontmatter、工具白名单或 `paths:` 规则。移植完成应以新会话验证发现、调用和产出。
