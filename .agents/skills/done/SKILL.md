# 收尾
1. 若 PLAN.md 验收全部通过，按 plan 技能迁出知识并归档；未完成不得归档。
2. 读取相邻 handoff 技能，覆盖更新 HANDOFF.md 的当下态。
3. 读取相邻 devlog 技能，按用户时区追加当天日志。
4. 用户明确要求提交或推送时才读取 git-push 技能执行；普通“收尾”止于状态和日志。
5. 汇报已完成、验证证据和未完成事项。提交信息可使用用户提供的文字，无需 $ARGUMENTS 宏。
