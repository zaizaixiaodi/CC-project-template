# handoff

HANDOFF.md 是**会自我冲刷的瘦缓冲区**，不是账本。核心：当下态覆盖，沉淀物流出。

## 会话开始

1. 读根目录 `HANDOFF.md`，从"当前 (Now)"接上进度。
2. 不存在则从 `templates/HANDOFF.md` 复制一份到根目录。

## 会话结束（更新纪律）

按段处理，每段规则不同：

- **当前 (Now)**：**覆盖重写**，不追加。写清在途的那一件事 + 下个 session 第一个具体动作。
- **计划 (Plan)**：勾掉完成项；done 太多就折叠成一行或删除。
- **在途决策 (Decisions)**：被推翻就**就地改**，不要叠加矛盾条目。
- **踩坑 (Gotchas)**：过时即删，只留还会再踩的。

## 冲刷规则（对抗膨胀的关键）

沉淀物**不要沉在 HANDOFF.md**，一旦稳定就流向已有三层，并从 HANDOFF.md 删除：

| 沉淀物稳定后（按性质分流） | 迁往 |
|---|---|
| 规范型（可验证的禁令/必须） | `CLAUDE.md` / `.claude/rules/` |
| 项目专属的描述型知识 | `docs/`（CLAUDE.md 留指针） |
| 个人/跨项目经验 | Harness 自动记忆（自动维护，无需手动搬） |

## 硬约束

- HANDOFF.md **≤ 80 行**，超了立即冲刷。
- 禁止 session 流水账（"Session 1 做了…，Session 2 做了…"）——这是 #1 膨胀源。
- 它是 handoff 为主、沉淀为辅；沉淀物该不断按性质流出归位，而非堆积。
